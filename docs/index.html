npm run bench:rgb

The playground uses the specialized kmeans_rgb function for palette discovery, then maps pixels to the nearest palette entry for the side-by-side preview. The benchmark measures the clustering call itself; browser results vary by CPU and browser.

Why WebAssembly?

Keep the pixels close to the math.

kmeans-wasm implements the Hamerly k-means algorithm in Rust and ships it as a small ES module. The release build enables WebAssembly SIMD and the playground keeps image decoding, clustering, and palette mapping entirely in the browser.
